# Sudustrial

|[ CurseForge ]()|[ Modrinth ]()|

This mod is built on Fabric. 
It was created to experiment with various game mechanics and offers a way to expand the 
gameplay experience.

## Overview
A Fabric mod for Minecraft built around one idea: make something interesting. It's a party of
different mechanics, their overrides and surprises.

### The TNT system
Sudustrial adds a single custom TNT entity that behaves completely differently depending on what 
block triggered it. Instead of dozens of unrelated explosive block classes, every variant — from 
a firework-quiet Party TNT to a Nuclear TNT, each with its own explosion algorithm tuned for 
what it's supposed to do:
+ Terraform the world into a theme,
+ Spawn mobs,
+ Buff or debuff everyone nearby
+ Mining,
+ Just blow up,
+ And Nuke the world up!

More than forty different types of TNT with ten tier each other. The ten highest tiers of nearly 
every TNT type can make bigger BOOM.

## Requirements
+ Minecraft 26.2
+ Fabric Loader
+ Fabric API

## Installation
1. Install Fabric Loader for Minecraft 26.2.
2. Download and install Fabric API.
3. Drop the Sudustrial .jar into your mods' folder.
4. Launch the game.
